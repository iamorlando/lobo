# lobo_replay

Market-data replay, custom adapters, and simulation for LOBO.

This is a supporting crate of [LOBO](https://github.com/iamorlando/lobo).
For the public Rust API, feature selection, and examples, start with the
[LOBO Rust guide](https://github.com/iamorlando/lobo/tree/main/rust/crates/lobo).
