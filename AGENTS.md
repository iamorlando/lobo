# Repository Agent Instructions

## Rust modification boundary


- Every file and crate under `rust/` is off limits for modification unless the user explicitly authorizes the exact work in the current request.
- Read-only inspection of Rust code is permitted when needed to understand its API, diagnose behavior, or explain existing changes.
- Do not create, edit, delete, refactor, reformat, or mechanically rewrite Rust files without explicit authorization. This includes running workspace-wide formatting or fix commands that would alter them.
